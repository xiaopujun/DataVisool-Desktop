# 一、设计定位

## 1.1 产品气质

* **类型**：B 端管理后台 / SaaS 控制台
* **风格关键词**：专业、简洁、安静、精致、科技感
* **视觉路线**：Dark Dashboard + Subtle Glow + Data-driven
* **避免方向**：

    * 不要赛博朋克式过度发光
    * 不要大面积复杂插画
    * 不要花哨渐变堆满页面
    * 不要“每块都是重点”

---

# 二、设计原则

## 2.1 信息优先

视觉服务于信息，不让装饰喧宾夺主。

## 2.2 统一优先

颜色、圆角、间距、阴影、文字层级必须统一。

## 2.3 对比克制

深色 UI 靠**层级对比**和**留白**，不是靠大量发光。

## 2.4 一页一个重点

页面最多只有 1~2 个主要视觉焦点。

## 2.5 组件系统化

所有 UI 必须可组件化，不做一次性视觉。

## 3.2 渐变规范

### 主按钮渐变

```text
linear-gradient(135deg, #4C8DFF 0%, #3B82F6 100%)
```

### 卡片轻渐变（可选）

```text
linear-gradient(180deg, rgba(255, 255, 255, 0.02) 0%, rgba(255, 255, 255, 0.00) 100%)
```

### 禁止

* 不允许一个页面出现 4 种以上独立渐变
* 不允许大面积高饱和渐变背景
* 不允许组件边框发彩光

---

## 3.3 阴影与发光

### 卡片阴影

```text
0 8px 24px rgba(0, 0, 0, 0.24)
```

### 浮层阴影

```text
0 12px 32px rgba(0, 0, 0, 0.32)
```

### 主按钮微发光（仅可选）

```text
0 0 0 1px rgba(255, 255, 255, 0.06), 0 6px 20px rgba(59, 130, 246, 0.22)
```

### 规范

* 页面中**只有主按钮、选中导航、关键状态**可轻微发光
* 普通卡片、表格、图表不要使用高强度 glow

# 四、排版系统

## 4.1 字体建议

中文优先：

* `PingFang SC`
* `HarmonyOS Sans SC`
* `Microsoft YaHei`

英文/数字优先：

* `Inter`

推荐组合：

```text
font-family: Inter, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif;
```

---

## 4.2 字号层级

| 类型           | 字号 | 行高 | 字重  | 用途         |
|--------------|----|----|-----|------------|
| `display-lg` | 40 | 48 | 700 | 超大数字/KPI重点 |
| `h1`         | 32 | 40 | 700 | 页面标题       |
| `h2`         | 24 | 32 | 600 | 模块标题       |
| `h3`         | 18 | 26 | 600 | 卡片标题       |
| `body-lg`    | 16 | 24 | 400 | 正文强调       |
| `body-md`    | 14 | 22 | 400 | 常规正文       |
| `body-sm`    | 13 | 20 | 400 | 辅助说明       |
| `caption`    | 12 | 18 | 400 | 标签/提示      |
| `kpi-number` | 48 | 52 | 700 | 核心指标数字     |

---

## 4.3 字体使用规则

* 页面标题：`h1`
* 卡片标题：`h3`
* 描述文案：`body-sm`
* 表格正文：`body-md`
* 次级信息：`caption`
* 数字类信息优先使用 `Inter`

# 八、组件设计标准

---

## 8.1 Sidebar（左侧导航）

### 尺寸

* 宽度：`240px`
* 一级菜单高度：`44px`
* 菜单内边距：左右 `16px`
* 图标尺寸：`18px`
* 图标与文字间距：`12px`

### 状态

* 默认：

    * 背景透明
    * 文本 `text-secondary`
* Hover：

    * 背景 `bg-hover`
    * 文本 `text-primary`
* Active：

    * 背景 `rgba(59,130,246,0.14)`
    * 左侧 2px 指示条 `primary`
    * 文本 `text-primary`

### 规范

* 当前选中项不能太亮
* 不建议大面积紫蓝渐变选中块
* 图标风格统一为线性图标

---

## 8.2 顶部 Header

### 内容

* 页面标题
* 页面描述
* 右侧快捷操作区（通知、按钮）

### 尺寸

* 标题与描述纵向间距：`8px`
* 操作区按钮高度：`40px`

---

## 8.3 Button（按钮）

### 主按钮

* 高度：`40px`
* 内边距：`0 16px`
* 圆角：`10px`
* 背景：`primary`
* 文字：`14px / 500 / white`

### 次按钮

* 背景：`rgba(255,255,255,0.04)`
* 边框：`1px solid border-default`
* Hover：背景变为 `bg-hover`

### 文字按钮

* 无背景
* 文本 `primary`
* Hover：透明度增强

---

## 8.4 KPI Card（统计卡片）

### 结构

* 左上：图标
* 中间：标题
* 主数字：大号数值
* 底部：同比/环比文案
* 右侧：迷你趋势线（可选）

### 规格

* 最小高度：`160px`
* 内边距：`24px`
* 圆角：`16px`
* 背景：`bg-surface-1`
* 边框：`border-default`

### 数值规则

* 主数字：`48px / 700`
* 单位与趋势说明：`13px`
* 趋势正向：`success`
* 趋势负向：`danger`

---

## 8.5 分析卡片（Chart Card）

### 结构

* 头部：标题 + 筛选器
* 内容：图表/数据
* 底部：更新时间或补充说明

### 规范

* 图表区域必须有足够留白
* 图表说明与颜色映射必须一致
* 图表只服务数据，不做纯装饰

---

## 8.6 最近更新列表

### 单项结构

* 图标容器
* 标题
* 副标题
* 时间

### 规格

* 单行高度：`64px ~ 72px`
* 行分隔线：`1px solid border-subtle`
* 标题：`14px / 500`
* 副标题：`12px / text-tertiary`
* 时间：右对齐 `13px / text-secondary`

---

## 8.7 Table（表格）

### 表头

* 高度：`44px`
* 背景：透明或极浅蒙层
* 字体：`13px / 500 / text-secondary`

### 表体

* 行高：`56px ~ 64px`
* 文字：`14px / 400 / text-primary`
* 行 Hover：`bg-hover`

### 规范

* 每列对齐方式固定
* 金额、数量、时间等采用统一对齐规则
* 操作列尽量右对齐

---

## 8.8 Tag / Status

### 尺寸

* 高度：`24px`
* 左右内边距：`10px`
* 圆角：`999px`

### 状态色

* 成功：绿色浅底 + 绿色文字
* 处理中：蓝色浅底 + 蓝色文字
* 警告：橙色浅底 + 橙色文字
* 失败：红色浅底 + 红色文字

例：

```text
success-bg: rgba(34, 197, 94, 0.14)
success-text: #4ADE80
```

---

## 8.9 Input / Select

### 规格

* 高度：`40px`
* 背景：`rgba(255,255,255,0.03)`
* 边框：`border-default`
* 圆角：`10px`
* 内边距：`0 12px`

### 状态

* Hover：边框加深
* Focus：`1px border-focus + 外圈光晕`
* Disabled：透明度降低

# 十、数据可视化规范

---

## 10.1 配色映射

| 数据类别     | 颜色        |
|----------|-----------|
| 项目 / 主资源 | `primary` |
| 视频       | `teal`    |
| 模型       | `purple`  |
| 时间 / 更新  | `orange`  |
| 异常       | `danger`  |

---

## 10.2 图表使用原则

* 只保留**有信息价值**的图表
* 迷你趋势线用于表达趋势，不显示复杂刻度
* 主图表必须有：

    * 标题
    * 图例
    * 颜色映射
    * 数据说明

---

## 10.3 Donut 图规范

* 环粗细：`14px ~ 18px`
* 中心显示总数
* 外部图例必须与颜色一一对应
* 不要使用过多分段，最好 `3~6` 项

# 十一、交互状态规范

| 状态       | 说明             |
|----------|----------------|
| Default  | 默认状态           |
| Hover    | 鼠标经过，轻微高亮      |

| Disabled | 禁用，弱化显示        |
| Loading  | 显示骨架屏或 spinner |
| Empty    | 空状态引导          |
| Error    | 错误提示明确         |

# 十二、动效规范

## 动效原则

* 快速、轻量、克制
* 重点在反馈，不在炫技

## 建议参数

* Hover：`120ms ~ 160ms`
* 普通切换：`200ms`
* 面板展开：`240ms`
* 缓动：`ease-out`

## 可用动效

* Hover 浅色过渡
* 卡片阴影轻微变化
* Tab / 菜单切换过渡
* 数字变化可用轻量 Count-up（可选）

## 禁止

* 大范围闪烁
* 强烈发光动画
* 背景持续流光
* 图表炫技特效

# 十三、响应式规范

---

## 断点

| 断点   | 宽度          |
|------|-------------|
| `xl` | ≥ 1440      |
| `lg` | 1280 ~ 1439 |
| `md` | 1024 ~ 1279 |
| `sm` | 768 ~ 1023  |
| `xs` | < 768       |

---

## 响应规则

### ≥1280

* 保持完整侧边栏
* KPI 四列布局
* 中部双栏布局

### 1024~1279

* KPI 可变为 2x2
* 中部双栏改为上下布局或 7:5 压缩布局

### <1024

* Sidebar 折叠为图标栏或抽屉
* 表格可改卡片式展示
* 图表与列表改纵向排列

# 十八、这套规范的核心控制点

如果你想让页面真正“专业”，最重要的是控制这几点：

1. **颜色控制在 1 主色 + 3 辅助色内**
2. **统一圆角：主要用 12 / 16**
3. **统一间距：主要用 16 / 24**
4. **边框尽量低对比，不要高亮描边**
5. **发光只给极少数重点元素**
6. **图表必须有信息价值**
7. **同类组件严格复用，不要每块都重新设计**
